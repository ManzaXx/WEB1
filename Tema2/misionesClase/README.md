# Misiones de clase · Tema 2 (JavaScript avanzado)

Aquí van los ejercicios y misiones que se hacen en clase durante el Tema 2. La entrega evaluable del tema es la M2, que está en [`../Async_Odyssey/`](../Async_Odyssey/).

Cada ejercicio va en su propia subcarpeta (`01-inmutabilidad/`, `02-pipeline/`…). Si un ejercicio usa Vite, recuerda el `.gitignore` con `node_modules/` y `dist/`. Del 01 al 11 se prueban abriendo su `index.html` en el navegador (comparten [`estilos.css`](estilos.css) y pintan su salida en la página además de en la consola; el 09 necesita internet). El 12 es un proyecto Vite (`npm install` y `npm run dev`) y el 13 se comprueba con `npm install` y `npm run check`. Marca la casilla cuando esté subido.

- [x] [01](./01-inmutabilidad/) · Inmutabilidad básica: ordenar sin modificar el original (`toSorted`)

- [x] [06](./06-clases-herencia/) · Clases y herencia: `Figura`, `Circulo`, `Rectangulo` y área total con `reduce`
- [x] [07](./07-map-set/) · `Map` para contar palabras y `Set` para las únicas
- [x] [08](./08-event-loop/) · Predecir el orden del event loop (`setTimeout` frente a `Promise.then`)
- [x] [09](./09-fetch-errores/) · `fetch` con `respuesta.ok` y manejo de errores (JSONPlaceholder)
- [x] [10](./10-combinadores-promesas/) · Comparar `Promise.all`, `allSettled` y `race` cuando una falla
- [x] [11](./11-tema-localstorage/) · Tema claro/oscuro guardado en `localStorage`
- [x] [12](./12-vite-ts/) · Primer proyecto con Vite (Vanilla + TypeScript)
