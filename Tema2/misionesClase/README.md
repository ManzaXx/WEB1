# Misiones de clase · Tema 2 (JavaScript avanzado)

Aquí van los ejercicios y misiones que se hacen en clase durante el Tema 2. La entrega evaluable del tema es la M2, que está en [`../Async_Odyssey/`](../Async_Odyssey/).

Cada ejercicio va en su propia subcarpeta (`01-inmutabilidad/`, `02-pipeline/`…). Si un ejercicio usa Vite, recuerda el `.gitignore` con `node_modules/` y `dist/`. Marca la casilla cuando esté subido.

## Ejercicios propuestos del tema

- [ ] 01 · Inmutabilidad básica: ordenar sin modificar el original (`toSorted`)
- [ ] 02 · Pipeline funcional encadenado (`filter`, `map`, `toSorted`)
- [ ] 03 · Agrupar aprobados y suspensos con `Object.groupBy`
- [ ] 04 · Copia superficial (spread) frente a profunda (`structuredClone`)
- [ ] 05 · Closure `crearMonedero` con saldo privado y error si queda negativo
- [ ] 06 · Clases y herencia: `Figura`, `Circulo`, `Rectangulo` y área total con `reduce`
- [ ] 07 · `Map` para contar palabras y `Set` para las únicas
- [ ] 08 · Predecir el orden del event loop (`setTimeout` frente a `Promise.then`)
- [ ] 09 · `fetch` con `respuesta.ok` y manejo de errores (JSONPlaceholder)
- [ ] 10 · Comparar `Promise.all`, `allSettled` y `race` cuando una falla
- [ ] 11 · Tema claro/oscuro guardado en `localStorage`
- [ ] 12 · Primer proyecto con Vite (Vanilla + TypeScript)
- [ ] 13 · Pasar el monedero del ejercicio 05 a TypeScript
