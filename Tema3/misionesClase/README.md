# Misiones de clase · Tema 3 (React Core)

Aquí van los ejercicios y misiones que se hacen en clase durante el Tema 3. La entrega evaluable del tema es la M3, que está en [`../Reactor_Core/`](../Reactor_Core/).

Lo más cómodo es un único proyecto Vite + React para todos los ejercicios (`npm create vite@latest ejercicios -- --template react`), con un componente por ejercicio en `src/ejercicios/`. Recuerda el `.gitignore` con `node_modules/` y `dist/`. Marca la casilla cuando esté subido.

## Ejercicios propuestos del tema

- [ ] 01 · Hola componente: `Saludo` con la prop `nombre`, pintado tres veces
- [ ] 02 · Tarjeta de perfil con `children` y «En línea» con `&&`
- [ ] 03 · Contador «+3» con la función actualizadora `(c) => c + 1`
- [ ] 04 · Lista de tareas sin mutar el estado y con `key` estable
- [ ] 05 · Filtro derivado: la lista filtrada se calcula en el render, no es estado
- [ ] 06 · Reloj con `useEffect`, `setInterval` y su limpieza (montar/desmontar)
- [ ] 07 · Levantar el estado entre dos componentes hermanos
- [ ] 08 · Tema claro/oscuro con `createContext` y `useContext`
- [ ] 09 · Carrito con `useReducer`
- [ ] 10 · Reto: refactor anti-efecto (quitar un `useEffect` que solo calcula un total)
