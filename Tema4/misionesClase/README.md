# Misiones de clase · Tema 4 (Formularios y datos remotos)

Aquí van los ejercicios y misiones que se hacen en clase durante el Tema 4 (U4: formularios con React Hook Form y Zod, accesibilidad, TanStack Query, CORS y seguridad). La entrega evaluable del tema es la M4, que está en [`../Full_Contact_Forms/`](../Full_Contact_Forms/).

Lo más cómodo es un único proyecto Vite + React para todos los ejercicios, con un componente por ejercicio en `src/ejercicios/`. Recuerda el `.gitignore` con `node_modules/`, `dist/` y `.env`. Marca la casilla cuando esté subido.

## Ejercicios propuestos del tema

- [ ] 01 · Formulario de contacto con `useForm`, `register` y `handleSubmit`
- [ ] 02 · Errores accesibles: `aria-invalid`, `aria-describedby` y foco en el primer error
- [ ] 03 · Esquema Zod con mensajes propios conectado con `zodResolver`
- [ ] 04 · Refinamiento entre campos: «repite la contraseña» con `refine` y `path`
- [ ] 05 · Lista dinámica con `useFieldArray` (añadir y quitar filas)
- [ ] 06 · `useQuery` con estados de carga, error y vacío
- [ ] 07 · `useMutation` + `invalidateQueries` tras crear un elemento
- [ ] 08 · Claves de query con parámetros (filtro o página) y `staleTime`
- [ ] 09 · Validar la respuesta de un API con `safeParse`
- [ ] 10 · Variables de entorno con Vite (`import.meta.env`, `.env.example`) y CORS
